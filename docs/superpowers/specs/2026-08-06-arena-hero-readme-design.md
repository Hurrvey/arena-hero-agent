# Arena Hero Agent README 设计

## 目标

把仓库根目录的 README 从只有标题的占位文档，完善为面向首次访问仓库者的中文快速上手文档。读者应当能够在不阅读实现细节的情况下完成依赖安装、API key 配置、战术启动、网页观察和本地测试。

## 受众与语言

- 主要受众是使用 Windows PowerShell 的中文用户。
- 正文使用中文；文件名、Python 标识符、命令和 SDK 名称保持英文原样。
- 文档不承诺固定排名或“保证第一名”，只说明战术目标和已验证行为。

## 范围

本次只更新 `README.md`，不改变战术代码、依赖版本、测试或运行协议。README 中的命令必须与当前仓库一致：

- 依赖安装使用 `python -m pip install -r requirements.txt`。
- 入口使用 `python .\balanced_tactic.py`。
- API key 使用 `ARENA_HERO_API_KEY` 环境变量，未设置时由脚本通过隐藏提示读取。
- 测试使用 `python -m pytest -q`。

## 内容结构

README 按“先运行、再理解、最后排错”的顺序组织：

1. 项目简介与能力边界。
2. 特性和战术优先级：Core 防守、Ranger/Vanguard 战斗、Worker 经济、恢复、Beacon 与保守生产。
3. 环境要求和安装。
4. API key 的安全配置；明确不要把密钥提交到 Git。
5. 启动、运行输出、网页监控和 `Ctrl+C` 停止方式。
6. 策略摘要，说明只使用当前可见状态、合法目标和确定性排序。
7. 测试与本地验证命令。
8. GitHub 远程仓库的首次推送和后续更新命令。
9. 常见错误：认证失败、`non-fast-forward`、依赖或 Python 版本问题。
10. 安全提醒、限制和许可证链接。

## 写作与安全约束

- 命令块可直接复制到 PowerShell；命令前说明其作用。
- 不显示真实凭据，不要求用户把 API key 发到聊天中，也不在示例中硬编码密钥。
- 说明运行进程必须保持打开，且网页手动行动可能覆盖同一 Tick 的 Agent 行动。
- 不复制完整 SDK 参考或内部设计文档，只保留使用者需要的摘要。
- 使用相对仓库链接，避免 README 在仓库迁移后失效。

## 验证标准

- README 中出现的文件、命令、环境变量和脚本入口均可在仓库中找到。
- README 修改后运行现有测试和 `git diff --check`，确保文档变更没有破坏代码或引入空白错误。
- 自检不存在未完成项、未替换的占位符或会诱导泄露密钥的示例。
